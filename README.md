# Portfólio - Moisés Neto

Portfólio profissional desenvolvido com Next.js, apresentando minha experiência como Desenvolvedor Frontend com foco em React, Next.js e automação com IA.

## 🛠️ Tecnologias

- **Framework:** Next.js 16 (App Router)
- **Linguagem:** TypeScript
- **Estilização:** TailwindCSS v4
- **Componentes:** shadcn/ui, Radix UI
- **Animações:** Framer Motion
- **Qualidade de código:** Biome (lint + format)

## 🚀 Como executar

```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento
npm run dev

# Build de produção
npm run build

# Iniciar produção
npm run start
```

## 📋 Scripts disponíveis

| Comando | Descrição |
|---------|-----------|
| `npm run dev` | Servidor de desenvolvimento |
| `npm run build` | Build de produção |
| `npm run start` | Iniciar servidor de produção |
| `npm run lint` | Verificar erros com Biome |
| `npm run format` | Formatar código |
| `npm run check` | Verificar código |
| `npm run check:fix` | Verificar e corrigir automaticamente |

## 📁 Estrutura

```
src/
├── app/              # Páginas e layout (Next.js App Router)
├── components/
│   ├── sections/     # Seções do portfólio (Hero, About, Skills, etc.)
│   └── ui/           # Componentes reutilizáveis
├── data/             # Dados do portfólio (experiências, habilidades, projetos)
└── lib/              # Utilitários
```
